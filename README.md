# AI Research Agent

An autonomous single-agent research tool built with Streamlit, CrewAI, Groq (Llama-3.3-70b), and DuckDuckGo Search.

## Features
- Web search integration using DuckDuckGo (no paid search API required).
- High-speed analysis using Groq's `llama-3.3-70b-versatile` model.
- Structured output rendering with downloadable Markdown reports.
